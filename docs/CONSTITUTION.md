# Cognitive Imprint 项目宪法

本文件是项目的最高治理文件。任何功能设计、代码改动、文档更新，如与本宪法冲突，以本宪法为准；如需违背，必须先修订本宪法并说明理由。

---

## 一、设计理念（为什么做这个工具）

本工具的核心目的：**通过抓取作者在网上的公开文章——例如 X（Twitter）上的帖子、个人 blog 的文章——通过对文章的读取，识别这个人的认知结构和认知判断。**

进一步的目标是让它可以**自动跟踪**：只要某个作者持续发布文章，系统就能持续读取，从而回答这些问题：

- 这个作者**这个阶段在想什么**？
- 这些文章**反映了他对什么问题有什么样的思考**？
- 他**产生了哪些判断**？

换句话说，本工具不是一个内容聚合器，也不是一个摘要工具。它关心的不是"文章说了什么"，而是"**写文章的这个人是怎么想的**"——他的推理习惯、论证结构、概念框架、判断倾向，以及这些东西随时间的演变。

### 由此推出的三条产品公理

1. **认知优先于内容。** 所有分析产出必须指向作者的认知模式（推理形状、论证缺口、框架稳定性、外推倾向），而不是文章内容的复述或摘要。一个只做摘要的功能不属于本项目。
2. **纵向跟踪是终局。** 单篇分析和单次报告只是中间形态；产品的最终形态是对作者认知轨迹的持续、自动的跟踪——能够呈现"这个阶段"与"上个阶段"的差异。所有架构决策都不得堵死这条演进路径（这也是文章逐篇存储原始文本和逐篇提取特征的原因）。
3. **只处理公开发表的文字。** 数据源永远限于作者主动公开发布的内容（RSS、公开 blog、公开帖子）。不抓取私密内容，不绕过访问控制，不推断作者的私人心理与动机——分析对象是"公开表达出来的认知"，不是"这个人本身"。

## 二、分析伦理红线

这些规则已固化在 `lib/analyzer.ts` 的 prompt 中，修改 prompt 时不得删除，只能加强：

1. **不奉承作者**（Do not flatter the author）。
2. **不推断私人心理与动机**。分析止于文本中可见的认知模式。
3. **三分法**：文本中明确存在的 / 合理推断的 / 不确定的，必须区分标注。
4. **每个结论必须有文本证据**（verbatim excerpts）。没有引文支撑的判断不得出现在报告中。
5. **对语料局限保持诚实**。语料不足时必须降低置信度（confidence: low/moderate/high 机制），不得用少量文本得出稳定结论。

## 三、工程原则

1. **简单优先。** MVP 阶段不引入队列、缓存、微服务等重型设施。当前形态（Next.js 单体 + Supabase Postgres + 经 OpenRouter 调用 LLM）在证明不够用之前不改。
   - **模型供应商可替换。** LLM 经 OpenRouter 统一接入，模型 ID 可由环境变量切换。这是刻意的解耦：分析质量依赖 prompt 与两段式管道设计，不绑定单一厂商。
2. **数据不销毁。** `raw_text`（原文）与 `extracted_features`（逐篇特征）是纵向跟踪的基础资产，只增不删；报告（`imprint_reports`）按版本追加，不覆盖历史。
3. **分析管道两段式。** 逐篇提取（per-document extraction）与语料级聚合（corpus-level aggregation）严格分离。逐篇特征是稳定的中间表示，聚合逻辑可以迭代重跑而无需重新抓取或重新分析原文。
4. **LLM 输出必须结构化。** 所有 LLM 调用要求返回严格 JSON，解析失败即报错，不做静默兜底。
5. **自动跟踪与人工导入并存。** 自动跟踪（定时 cron + 一键导入）依赖 `url`/`guid` 唯一约束去重，并设每轮抓取上限以适配 serverless 超时；人工勾选导入作为兜底路径保留，用于自动路径失败或需要精细挑选语料的场合。

## 四、演进路线（与理念对应）

| 阶段 | 能力 | 状态 |
|---|---|---|
| v1.0 | 单作者、RSS 手动导入、逐篇分析、版本化 imprint 报告、Markdown 导出 | ✅ 已实现 |
| v1.1 | 定时自动抓取（Vercel Cron 每日 → `/api/track`）+ 作者页一键自动导入 + "Recent focus" 近期思考卡片，实现"自动跟踪" | ✅ 已实现 |
| v2.x | 认知轨迹对比：同一作者不同时期报告的 diff，回答"这阶段在想什么、和上阶段比变了什么" | 规划中 |
| 更远 | 多源接入（X 帖子等公开来源）、多作者认知结构对比 | 构想 |

明确排除（任何版本都不做）：

- 写作风格模仿 / 代笔
- 抓取非公开内容或绕过平台访问控制
- 对作者私人心理、健康、动机的画像
